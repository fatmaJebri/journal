What is Git and How to Use It
1) Git vs GitHub
Git is like a super-powered "save" button for my computer It remembers every single change I make to my files GitHub is like a Google Drive or cloud storage for my code It keeps my saved work safely online so I never lose it

2) Core Commands
git clone: Downloading a project from the internet to my computer for the first time

git pull: Checking for new updates online and downloading them to my computer

git add: Picking exactly which changed files I want to save

git commit -m: Actually saving those files and leaving a little sticky note explaining what I did

git push: Uploading all my new saves from my computer up to the internet
